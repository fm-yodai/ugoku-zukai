解説動画の画風比べ

同じ台本・同じ声（VOICEVOX:ずんだもん、約 28 秒）を、4 つの作り方で描きました。題材は架空の「経費申請が支払われるまで」です。上のボタンで切り替え、再生ボタンから音つきで見てください。

作り方ごとの違い

① Manim② SVG 3b1b 調③ SVG 手描き調④ manim-web
描くものPython が mp4 を書き出す台本 JSON をブラウザのプレーヤーがその場で描く（②と③は画風の定義だけが違う）Manim と同じ書き方で、ブラウザの Canvas に描く
claude.ai で動くか未確認（描画の部品をその場でビルドする必要がある）動く見込み（サンドボックスで HTML 1 枚を作るだけ。検証済みの WebAudio 再生）動く見込み・要確認（HTML 1 枚。ただし本体 約 3.2MB を CDN から読むので、claude.ai の Artifact で読めるかは未確認）
作る時間（この 28 秒）手元の CPU で描画 約 2〜3 分（720p）描画は不要（開いた瞬間に描く）。作るのは HTML 1 枚だけ描画は不要。ただし今回は座標と動きを 1 場面ずつ手で書いた（作るのに 7 分ほど）
ファイルmp4 0.6MB（720p）HTML 0.32MB（音声込み）HTML 0.31MB（音声込み）＋ライブラリ 約 3.2MB（CDN）
配置ELK を Python から呼ぶ。凡例・層の帯の詰め方まで作り込み済み同じ ELK をブラウザで呼ぶ。凡例などの作り込みはまだ手置き（座標を直接書いた。自動配置はない）。人のアイコン・斜めの矢印など自由度は高い
見た目の特徴文字が大きく、図が画面いっぱいに広がる。字幕は焼き込み線を引く・点が流れる動きは①に近い。文字はやや小さめ線がペンで描かれていく。非開発者には親しみやすい3b1b の配色と細い線で雰囲気は近い。日本語は画像として貼るので、文字を書き順で描く演出は使えない
途中から見る・mp4mp4 なのでどこでも再生できるどこへでも飛べる（画面が時刻 t だけで決まる）。mp4 はブラウザで書き出す想定（未実装）Manim 流の play では途中へ飛べず、②と同じく「時刻 t の関数」を自前で書いて飛べるようにした

②③④は見比べ用の試作です。④は 0.x 版（manim-web 0.41.0）で、ドキュメントにない不具合を 3 つ回避しています。台本の書き方（ショット DSL）は①の語彙のうち、全体図・点の移動・戻りの矢印・強調・薄くする・札だけを移しています。
